# Boora Dheeraj Sri Krishna — Portfolio

A responsive, single-page personal portfolio with a dark editorial visual direction.

## Run locally

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev` and open the shown local address.

## Customization

- Update page content in `index.html`.
- Update visual styling and responsive behavior in `style.css`.
- Contact links and social profiles use the provided profile details.

## Production

Run `npm run build` to create a deployable `dist` folder. The project can be deployed to Vercel or Netlify.
