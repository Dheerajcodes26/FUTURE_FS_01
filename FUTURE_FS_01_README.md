1. Create a professional personal portfolio website.
2. Showcase my technical skills and development experience.
3. Present my projects in an organized and visually appealing manner.
4. Provide an interactive way for visitors to learn about my background.
5. Provide contact options for recruiters, clients, and other professionals.
6. Make the website responsive across desktop, tablet, and mobile devices.
7. Implement modern UI/UX principles and smooth animations.
8. Follow basic SEO practices to improve discoverability.
9. Deploy the website publicly using GitHub Pages.
10. Maintain the complete source code in a public GitHub repository.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Dheerajcodes26/FUTURE_FS_01.git
```

### 2. Navigate into the project

```bash
cd FUTURE_FS_01
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The development server will provide a local URL, usually:

```text
http://localhost:5173/
```

## 🏗️ Production Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
